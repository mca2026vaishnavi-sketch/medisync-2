# MediSync — Dark Futuristic Edition

Android Java app for health profile, medicine tracking, reminders, appointments, medical reports, emergency contacts and MediBot.

## Build APK without Android Studio on your laptop
1. Create a GitHub repository and upload this project.
2. Open **Actions** in the repository.
3. Select **Build MediSync APK** and choose **Run workflow** (or push to `main`).
4. Open the completed workflow run and download the `MediSync-debug-apk` artifact.
5. Extract the downloaded artifact ZIP on your Android phone, tap `app-debug.apk`, and allow installation from that source when Android asks.

The APK is a debug build for testing, not a Play Store release. Review notification permissions and test reminders on your own device.
